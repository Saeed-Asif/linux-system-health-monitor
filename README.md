# Automated Linux System Health Monitoring Tool

A beginner-friendly DevOps mini project built using Bash scripting on Linux.

This tool automatically generates a detailed system health report containing:

- System uptime
- Memory usage
- Disk usage
- CPU load
- Top memory-consuming processes
- Logged-in users
- Network IP information

The generated report is saved inside the `reports/` directory.

# 🚀 How to Run

## 1️⃣ Clone Repository

```bash
git clone YOUR_REPOSITORY_LINK
```

---

## 2️⃣ Move into Project Directory

```bash
cd linux-system-health-monitor
```

---

## 3️⃣ Give Execute Permission

```bash
chmod +x monitor.sh
```

---

## 4️⃣ Run Script

```bash
./monitor.sh
```
